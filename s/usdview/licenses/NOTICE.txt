Tomorrow Open Source Technology License 1.0 — the same license as OpenUSD
itself (see LICENSE).

This project is an independent port. It is not affiliated with, endorsed
by, or sponsored by Pixar Animation Studios or the Alliance for OpenUSD.
The `pxr/**` layout and the module names
mirror the upstream OpenUSD source tree this project ports; they imply no
affiliation, and no trademark rights are claimed or granted (see LICENSE,
Section 6).

Each ported source file starts with a header naming the upstream files it
ports, their copyright holders and their licence. This file lists every
upstream project whose code or data ships in this repository, its packages
and the built viewer, and reproduces the notices their licences require.
